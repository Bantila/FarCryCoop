# Far Cry (2004) — план: выбор миссий для всех игроков и фан-режимы

English version: [PLAN-fun-mode.md](PLAN-fun-mode.md)

Статус: **отложено** (2026-10-19). Владелец вернётся к плану после оптимизаций (подлагивания, чекпоинты, сейвы). Код ещё не написан.

## Зачем

Сейчас все команды `coop_*` работают только в консоли хоста. У клиента они тоже зарегистрированы (`AvailableMods.lua` загружается на каждой машине), но выполняются локально: `coop_map` на клиенте поднял бы у него свой сервер. Владелец хочет, чтобы любой игрок сам запускал любую сюжетную миссию, плюс фан-функции: огонь по своим и другие.

Решения (владелец сказал «просто делай»):

- Интерфейс — консоль, как сейчас. Меню — позже, если консоль окажется неудобной.
- Карта одна на всех. Любой игрок меняет её для всех, без голосования (кооп друзей).
- Выбор оружия — в лаунчере, позже (решение владельца). До тех пор есть `coop_weapons`.
- Огонь по своим по умолчанию выключен. Сейчас он фактически включён и не проверен: COOP `GameRules:OnDamage` отбрасывает только попадания по ИИ, а `CHIT` принимает в цель игрока.

## Изменения

### 1. Любой игрок запускает команды (`Scripts/Multiplayer/AvailableMods.lua`)

- Хелпер `CoopCommand(name, func, help)`: регистрирует `Game:AddCommand(name, "CoopRun('"..name.."', %line)", help)` и кладёт `func` в `COOP_Commands[name]`.
- `CoopRun(name, line)`: если `Game:IsServer()`, вызвать `COOP_Commands[name](line, _localplayer)`; иначе, если есть `Client`, отправить `Client:SendCommand("CCMD "..name.." "..line)`; иначе написать в лог «не подключён».
- Перевести все `Game:AddCommand("coop_...")` на `CoopCommand`. Функции получают `line` строкой (`%line` уже приходит строкой: `CoopMap(%line)` работает) и вторым аргументом игрока, который запустил команду.
- `coop_spawn` сейчас использует `%1`: перевести на `%line` и `tonumber`.

### 2. Сервер принимает команды клиентов (`Scripts/COOP/gamerules.lua`)

- В `GameRules:OnClientCmd`: если `tk[1] == "CCMD"`, взять `f = COOP_Commands[tk[2]]`. Если функция есть, вызвать её через `call(...)` с логом ошибки (как `CoopWakeError`), передав строку после имени команды (`strsub` от исходного `cmd`) и игрока слота. В лог сервера: `coop: <имя игрока> ran <cmd>`.
- Разрешены только имена из `COOP_Commands`: белый список — это сами команды.

### 3. Список миссий: `coop_maps`

- Жёсткий список 20 карт кампании из папки `Levels` игры (без `mp_*`, `Demo`, `newcontrol`): Training, Carrier, Fort, Pier, Research, Treehouse, Bunker, Rebellion, Steam, Cooler, Control, Archive, Catacombs, Factory, Dam, Boat, River, Swamp, Regulator, Volcano. Порядок по памяти — поправить по игре.
- `coop_map` без аргумента тоже печатает этот список.

### 4. Выбор оружия — отложен до лаунчера

- Сейчас не делаем. Пока `coop_weapons` (всё оружие всем) становится доступен любому игроку.

### 5. Фан-функции

- `coop_ff [0/1]`: огонь по своим, по умолчанию `COOP_FF = 0`. В COOP `GameRules:OnDamage`: если `COOP_FF ~= 1`, стрелок и цель — люди (`not s.ai`, `not t.ai`) и `s ~= t`, урон отбросить. Урон по себе (гранаты, падение) не трогать.
- `coop_dmg [x]`: множитель урона игроков по ИИ, по умолчанию `COOP_Dmg = 1`; `10` — враги падают с одного попадания. В том же `OnDamage`: `hit.damage = hit.damage * COOP_Dmg` для попаданий игрок -> ИИ.
- `coop_god`, `coop_noclip`, `coop_weapons` становятся доступны всем — тоже фан.
- **RocketMod by FarOut** (версия 2.1 NATIVE). Источник владельца: https://www.speedrun.com/static/resource/ly1lr.zip?v=7179c9c ; локальная копия владельца: `RocketMod_Release_2.1_NATIVE_3c6dcb9c.zip` в его папке загрузок на диске C:. Описания в сети не нашёл (ModDB и speedrun.com отдают 403). Шаги:
  1. Загрузить `. E:\FarCryCoop\env.ps1`. Один раз скопировать архив с диска C: в `E:\FarCryCoop\Downloads\RocketMod\` (владелец разрешил это исключение из правила 2 CLAUDE.md, 2026-10-19). Больше диск C: не трогать. Записать SHA-256.

  3. Прочитать readme: разрешения на перенос.
  4. Если это скрипты Lua/XML: перенести суть в мод FarCryCoop как переключатель `coop_rockets [0/1]` (через `CoopCommand`; если эффект клиентский, ещё `ServerCommandTable` у клиентов). ## Проверка (владелец, в игре)

1. Хост: `coop_map Pier`, клиент подключился.
2. Клиент: `coop_map` печатает список карт; `coop_map Fort` переносит обоих на Fort, клиент не вылетает; `coop_weapons` с клиента работает.
3. Клиент стреляет в хоста: урона нет. После `coop_ff 1` урон есть. Хост стреляет в клиента — то же самое.
4. `coop_dmg 10`: враги падают с одного попадания у обоих игроков.
5. `coop_rockets 1`: эффект RocketMod виден у хоста и у клиента; `coop_rockets 0` выключает его.
6. В логе сервера есть строки `coop: <имя> ran ...`.
