# FarCryCoop — кооператив кампании Far Cry (2004)

English version: [README.md](README.md)

Проходите оригинальную кампанию Far Cry вместе: один игрок хостит карту кампании, друзья подключаются и проходят миссии рядом. Это мод: набор скриптов в `Mods\FarCryCoop`, небольшой ASI-плагин, который чинит сетевой код движка для карт кампании, и лаунчер с лобби. Файлы игры не заменяются.

**Статус: 0.2 бета, в активной разработке** (начата 2026-10-18). Проверено на 2 игроках, Far Cry 1.4 (Steam). Цель: до 4 игроков. Будут баги.

## Что работает

Официального кооператива в Far Cry нет. Кампания и так работает как локальный сервер плюс локальный клиент, и мод строится на этом: хост запускает карту кампании как сетевой сервер с одиночными правилами, а остальные игроки подключаются как удалённые клиенты.

| Что | Состояние | Примечания |
|---|---|---|
| Карта кампании как сервер | работает | в игровом клиенте (хост играет сам, listen-сервер) или в `FarCry_WinSV.exe` (выделенный) |
| Удалённые игроки: движение, оружие, стрельба | работает | движок терял ~40% каждого снапшота на картах кампании; ASI это чинит |
| Попадания удалённых игроков по врагам | работает | попадания считает клиент (`CHIT`), применяет сервер |
| ИИ врагов, ближний бой | работает | спящий ИИ просыпается рядом с игроками; ближний бой работает на выделенном сервере |
| Триггеры зон для удалённых игроков | работает | миссии, которые идут дальше по «дойди до места» |
| Смена и перезапуск карты | работает | друзья остаются подключёнными |
| Задачи миссии и сообщения | работает | сервер пересылает их каждому игроку |
| Выход из техники и с параплана | работает | сервер говорит клиенту отпустить место |
| Бочки и ящики, сдвинутые на сервере | работает | сдвинутые взрывами; толкать их не может ни один игрок, включая хоста |
| Русская раскладка клавиатуры | работает | раньше игра с ней теряла настройки клавиш |
| Чекпоинты и возрождение | частично | точка возрождения идёт за чекпоинтами; прыжки по чекпоинтам 9 уровней сработали для обоих игроков; возрождение клиента на чекпоинте после смерти не видел |
| Цвет рубашки | работает | 10 цветов из лаунчера; другим игрокам ставится мультиплеерная модель Джека с цветовой маской |
| Выкладка | проверяется | 4 оружия из 11, выбираются в лаунчере; включает хост |
| Лобби | проверяется | список игроков с цветами и выкладками; «Начать» с двумя играми ещё не пробовали |
| Вход через друзей Steam | проверяется | мост работает как Spacewar (AppID 480): его запуск, вход в Steam, presence «connect» и подключение игры через туннель проверены на одном ПК; Join от настоящего друга не проверен |
| Заставки | частично | хост их видит; подключившиеся — нет |
| Дельтаплан | работает | для каждого следующего игрока появляется копия; другим набирающий высоту дельтаплан кажется падающим |
| Багги и лодки (2 места) | работает (проверено на двух играх) | на стартовой точке появляется копия, если игроки не помещаются |
| Вертолёты | частично | вертолёт, который двигается у хоста, клиент повторяет; ещё не двигавшийся висит у клиента на другой высоте; настоящий полёт в миссии не видел |
| Сохранения | только у хоста | автосейв на чекпоинтах, `coop_save` / `coop_load` (F6 / F7 не проверены), старт из сохранения в лаунчере; игроки, оружие и убитые враги, без хода миссии |
| Сложность | работает | лаунчер или `#CoopDifficulty(n)`; пять уровней меню одиночной игры |
| Уровни | 20 из 20 грузятся | Treehouse и Swamp потребовали обхода (запечённые состояния физики пропускаются, [#1](https://github.com/Bantila/FarCryCoop/issues/1)); смена уровня иногда роняет хоста (3 из 11 запусков на Bunker → Steam, 4 из 25 на Cooler → Boat, [#2](https://github.com/Bantila/FarCryCoop/issues/2)) |

Полный журнал исследования со всеми фиксами, адресами и проверками: [games/far-cry/NOTES.ru.md](games/far-cry/NOTES.ru.md).

## Быстрый старт

Нужно: Far Cry 1.4 (версии из Steam и GOG — 1.4), Windows 10 или 11. У всех должна быть одна версия мода.

1. Получите архив для игроков `FarCryCoop-<версия>.zip` у владельца проекта или соберите его (см. [Сборка из исходников](#сборка-из-исходников)).
2. Скопируйте `Mods`, `Bin32` и `FarCryCoopLauncher.exe` в папку Far Cry (Steam: `steamapps\common\FarCry`). Разрешите слияние. Если в `Bin32` уже есть ASI-загрузчик (`version.dll` от широкоэкранного фикса), `dinput8.dll` не копируйте.
3. Запустите `FarCryCoopLauncher.exe`.
4. Хост: выберите карту, нажмите «Создать лобби». Друзья: введите IP хоста, нажмите «Войти в лобби». Хост нажимает «Начать».

Три способа позвать друзей: список друзей Steam через мост Spacewar (без IP и портов), виртуальная сеть (Radmin VPN, Hamachi, ZeroTier) или проброс портов UDP 49001 (игра) и TCP 49002 (лобби). По шагам, плюс список проверок для бета-теста: [games/far-cry/release/INSTALL.ru.md](games/far-cry/release/INSTALL.ru.md).

Без лаунчера: запустите `Bin32\FarCryCoop.bat`. Хост набирает в консоли (`~`) `#CoopMap("pier")`, друзья — `connect <IP хоста>`.

## Лаунчер и лобби

`FarCryCoopLauncher.exe` (Rust + Tauri, одно окно в стиле меню игры):

- **Игрок:** имя, цвет рубашки (10 цветов мультиплеерной палитры), 4 оружия из 11 для выкладки (Machete, Falcon, MP5, P90, M4, AG36, OICW, Shotgun, SniperRifle, M249, RL).
- **Лобби:** хост создаёт его, друзья входят по IP. Все видят список игроков с цветами рубашек и выкладками, а также карту и режим выкладки хоста.
- **Начать:** игра запускается у всех; у хоста загружается карта, а друзья подключаются, когда сервер хоста поднят.
- **Приглашение Steam:** запускает игру и ждёт приглашения хоста из списка друзей Steam.
- **Тест на одном ПК:** игра хоста слева, а когда её сервер поднят, справа игра клиента, которая подключается сама.
- **Выкладка включена:** каждый спавн даёт ваши 4 оружия с полным боезапасом. Оружие, отобранное у врагов, переходит на следующий уровень, и там боезапас пополняется.

С игрой лаунчер общается только через два файла: `Mods\FarCryCoop\prefs.lua` (цвет, оружие, режим выкладки) и `Mods\FarCryCoop\join_<pid>.txt` (одна строка консоли, её выполняет ASI в игре с этим номером процесса; Steam-мост пишет в общий `join.txt`). Подробности: [games/far-cry/launcher/README.ru.md](games/far-cry/launcher/README.ru.md).

## Команды консоли хоста

Набираются в консоли (`~`) в виде `#Функция()`; короткая форма (`coop_god 1`) пока работает только на выделенном сервере.

| Команда | Что делает |
|---|---|
| `#CoopMap("pier")` | хостить карту кампании; повторно: сменить карту, друзья остаются |
| `#CoopMap(COOP_Map)` | перезапустить текущую карту |
| `#CoopGod(1)` / `#CoopGod(0)` | бессмертие для всех |
| `#CoopAmmo()` / `#CoopWeapons()` | полный боезапас / всё оружие для всех |
| `#CoopGoto()` / `#CoopGoto(3)` | список чекпоинтов / перенести всех на чекпоинт 3 |
| `#CoopGather()` | собрать всех у хоста |
| `#CoopNoclip(1)` | режим полёта для всех |
| `#CoopBot()` | создать бота-напарника, который идёт за ближайшим игроком |
| `#CoopSave("имя")` / `#CoopLoad("имя")` | сохранить / загрузить кооперативную игру (имена по умолчанию `quick` и `auto`) |
| `#CoopDifficulty(2)` | сложность 0–4 (лёгкая, средняя, сложная, ветеран, реализм) |
| `#CoopMonitorSet(1)` | раз в секунду писать в лог состояние игроков, ИИ и техники (отладка) |

## Как это устроено

```
 FarCryCoopLauncher.exe ──TCP 49002── лаунчеры друзей (лобби)
        │ prefs.lua, join_<pid>.txt
        ▼
 FarCry.exe -DEVMODE -MOD:FarCryCoop
  ├─ Mods\FarCryCoop\FarCryCoop.pak   Lua: тип игры COOP = одиночные правила + кооп-фиксы
  └─ Bin32\FarCryCoopNet.asi          C: перехваты в CryGame.dll 1.4 по адресам
        │ UDP 49001 (собственный сетевой код игры)
        ▼
 FarCry.exe друзей
```

- **Тип игры `COOP`** (Lua, `Scripts/COOP/`): одиночные правила плюс то, чего им не хватает в сетевой игре. Пробуждение ИИ рядом с любым игроком, ближний бой ИИ без событий анимации, чекпоинты для каждого игрока, пересылка задач миссии и роликов клиентам, попадания на стороне клиента, выход из техники, цвет рубашки и выкладка.
- **ASI-плагин** (`asi/FarCryCoopNet.c`, собран без CRT и Windows SDK). Он перехватывает функции оригинального `CryGame.dll` 1.4 по адресам; адреса найдены через REA/Ghidra и сверены с исходниками официального MOD SDK 1.4:
  - **Снапшоты:** уходят по приоритету и укладываются в лимит потока 8992 бита, поэтому карты кампании (~650 сетевых сущностей) доходят до клиента.
  - **Триггеры зон** для удалённых игроков.
  - **Выделенный сервер:** колбэки заставок и звука больше его не роняют, а разрешение таймера 1 мс даёт 35 снапшотов в секунду.
  - **Предметы,** сдвинутые на сервере, отправляются клиентам.
  - **Клавиатура:** раскладка US для таблицы клавиш игры.
  - **Консоль:** одна строка консоли из `join_<pid>.txt` (лаунчер) или `join.txt` (Steam-мост) выполняется в главном потоке.
- **Steam-мост** (`steam/FarCryCoopSteam.c`): работает как Spacewar, показывает «Присоединиться» в списке друзей Steam и пробрасывает подключение через `127.0.0.1:49011`.
- **Лаунчер** (`launcher/`): Rust + Tauri 2, одна HTML-страница, лобби по TCP.

Бинарники игры не меняются. `CryGame.dll`, пересобранный из SDK, попробовали и отказались: ему нужен VC 7.1 со STLport, а ничего сверх ASI он не дал.

## Известные ограничения

- Вертолёты (`Gunship`, `CargoChopper`): клиент повторяет вертолёт, как только тот сдвинулся у хоста; до этого он висит до 34 м выше. Настоящий полёт в миссии (босс на Boat) не видел.
- Treehouse и Swamp раньше падали при загрузке уровня (`CRITICAL ERROR:: ReadPacked i== 20`); теперь ASI пропускает состояние физики, запечённое в файле уровня у некоторых сущностей, и эти объекты стоят там, где их ставит уровень ([#1](https://github.com/Bantila/FarCryCoop/issues/1)).
- **Смена уровня иногда роняет хоста** (случайная порча кучи в `CrySystem.dll`; замечена на Bunker → Steam и Cooler → Boat, несколько раз из десяти): [#2](https://github.com/Bantila/FarCryCoop/issues/2).
- После переноса (прыжок на чекпоинт, загрузка) клиента, пропустившего его, сервер переносит снова, в том числе если он провалился сквозь землю ([#3](https://github.com/Bantila/FarCryCoop/issues/3), закрыта); ошибка в разговорах ИИ на Bunker закрыта защитой ([#4](https://github.com/Bantila/FarCryCoop/issues/4), закрыта). Техника, где мест меньше, чем игроков (Swamp, багги): [#5](https://github.com/Bantila/FarCryCoop/issues/5).
- Другим игрокам дельтаплан, набирающий высоту, кажется падающим.
- Ни один игрок не может толкать бочки и ящики, включая хоста.
- Подключившиеся не видят заставок; вступительная заставка у хоста проверена не на всех картах.
- Сохранения хранят только игроков, оружие и убитых врагов; после загрузки скрипт миссии идёт с начала карты (триггеры, предметы и техника не сохраняются).
- Прыжки ИИ и другие действия ИИ, завязанные на анимацию, на выделенном сервере не происходят.
- Чат и консоль в игре печатают только латиницу.
- PunkBuster остаётся выключенным; мод его не трогает.

## Планы

1. Найти случайное падение при смене уровня ([#2](https://github.com/Bantila/FarCryCoop/issues/2)), затем повторить обход всех 20 уровней за один прогон (Treehouse, Swamp, Factory, Dam и Volcano обойдены после обхода проблемы).
1a. Проверить в игре вдвоём цвет рубашки, выкладку, «Начать» в лобби и клавиши сохранения F6 / F7.
2. Вход через Steam с настоящим вторым аккаунтом друга.
3. Панель хоста внутри игры (меню ESC вместо консоли), запуск любой миссии любым игроком, переключатель огня по своим: [games/far-cry/PLAN-fun-mode.ru.md](games/far-cry/PLAN-fun-mode.ru.md).
4. Заставки у подключившихся (написаны, в игре не видел) и настоящий полёт вертолёта.
5. Сохранять и ход миссии (триггеры, задания, предметы).
6. Список игроков во время игры в лаунчере.

## Сборка из исходников

Каждый скрипт загружает `E:\FarCryCoop\env.ps1` и работает внутри `E:\FarCryCoop` (см. [docs/workspace.ru.md](docs/workspace.ru.md)). Инструменты: MSVC 14.44 (x86, копия только для чтения), x86-библиотеки Windows SDK, Rust (i686) для лаунчера.

| Часть | Команда | Результат |
|---|---|---|
| Скрипты мода | `& games\far-cry\mod\deploy.ps1` | `<игра>\Mods\FarCryCoop\FarCryCoop.pak` |
| ASI-плагин | `& games\far-cry\asi\build.ps1` | `Temp\asi\FarCryCoopNet.asi` |
| Steam-мост | `& games\far-cry\steam\build.ps1` | `Temp\steam\FarCryCoopSteam.exe` |
| Лаунчер | `& games\far-cry\launcher\build.ps1` | `Temp\launcher\FarCryCoopLauncher.exe` |
| Архив для игроков | `& games\far-cry\release\release.ps1` | `Temp\release\FarCryCoop-<версия>.zip` |

```

  NOTES.md, NOTES.ru.md          журнал исследования: каждый спайк, фикс и адрес
  PLAN-fun-mode.md               план панели хоста и «весёлых» функций

```

## Предшественники и благодарности

- [Assault Coop](https://www.moddb.com/mods/assault-coop) от FlameKnight7 (2011): 7 переделанных карт кампании для кооператива. Подсказал идею ретрансляции триггеров зон с клиента. Его скрипты нельзя использовать без разрешения автора, поэтому его кода здесь нет.
- [FCAV](https://farcry1.itch.io/far-cry-advanced-version): кооператив анонсирован, но не вышел.
- Методика: [coop-anything](https://github.com/cranebeaker/coop-anything).
- Структура README — по примеру кооп-проектов вроде [TES3MP](https://github.com/TES3MP/TES3MP) и [sm64coopdx](https://github.com/coop-deluxe/sm64coopdx).
- Официальный CryENGINE MOD SDK 1.4 (исходники `CryGame.dll`, по ним сверяются адреса). Утёкшие полные исходники движка не используются.
- [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader) (MIT) загружает плагин.
